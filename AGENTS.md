# Guia para IA — Atividade6-EdN

Exercícios de senha aleatória e consumo de APIs públicas (perfil, CEP e câmbio).

1. Ler cada enunciado antes de alterar o algoritmo.
2. Não trocar fórmulas e formato de saída exigidos pela atividade.
3. Preservar nomes em português e arquivos: 1/gerador_senha.py, 2/perfil_aleatorio.py, 3/consulta_cep.py, 4/cotacao_moeda.py.
4. Não adicionar dependências externas sem necessidade.
5. Evitar credenciais e dados reais em código ou logs.
6. Testar sintaxe e comparar entradas/saídas para cada script; testes de documentação não validam comportamento.

Atenção: As atividades dependentes de APIs exigem conexão e disponibilidade externa; evitar salvar dados pessoais reais. Para senhas reais, revisar uso de geração criptográfica.
