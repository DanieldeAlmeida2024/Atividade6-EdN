# Requisitos iniciais — Atividade6-EdN

Exercícios de senha aleatória e consumo de APIs públicas (perfil, CEP e câmbio).

- RF-01 Um arquivo por atividade, com comportamento definido no README.
- RF-02 Receber valores e apresentar resultados corretos.
- RF-03 Tratar erros previstos no enunciado.
- RNF-01 Código legível e nomes consistentes em português.
- RNF-02 Scripts independentes, sem arquitetura empresarial inventada.
- RNF-03 Testes com exemplos concretos e limites.

As atividades dependentes de APIs exigem conexão e disponibilidade externa; evitar salvar dados pessoais reais. Para senhas reais, revisar uso de geração criptográfica.
